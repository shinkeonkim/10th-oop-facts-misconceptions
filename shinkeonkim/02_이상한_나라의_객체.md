- (생각) 문장은 아니지만, 전체적으로 이상한 나라의 앨리스를 이용해서 객체의 상태와 행동을 설명한 부분이 좋았음. 

- 앨리스의 상태를 결정하는 것은 행동이지만 행동의 결과를 결정하는 것은 상태다.

p.53
- 객체의 행동은 상태에 영향을 받는다.
- 객체의 행동은 상태를 변경시킨다.

-> (생각) 따라서, 객체의 행동과 상태는 서로 영향을 주고 받는 관계이다. 

- 상호작용이 현재의 상태에 어떤 방식으로 의존하는가
- 상호작용이 어떻게 현재의 상태를 변경시키는가

-> (생각) 과거 또는 미래의 상태는 여기서 고려할 수 있는가? 현재의 상태에 의존하는 것이라면, 과거의 상태를 고려할 수 있을까? 미래의 상태를 고려할 수 있을까?

p.54 

- 어떤 객체도 섬이 아니다.

- Query 와 Command

- 객체지향 설계자로서 우리의 목적은 현실을 모방하는 것이 아니다. 단지 이상한 나라를 창조하기만 하면 된다.
  - (생각) 트럼프가 팔다리가 달리고, 고양이가 말을 하고, 앨리스가 키가 커지고 작아지는 이상한 나라를 창조하는 것처럼, 객체지향 설계자는 현실을 모방하는 것이 아니라, 객체의 상태와 행동을 통해 이상한 나라를 창조하는 것이다.
- 현실을 닮아야 한다는 어떤 제약이나 구속도 없다. 여러분이 창조한 객체의 특성을 상기시킬 수 있다면 현실 속의 객체의 이름을 이용해 객체를 묘사하러, 그렇지 않다면 깔끔하게 현실을 무시하고 자유롭게 여러분만의 새로운 세계를 창조하기 바란다. 앨리스를 매혹시킨 이상한 나라가 그런것처럼 말이다.
  - (생각) 누군가와 협업을 하는 상황이라면 이런 이상한 나라의 창조가 가능한가? 현실을 무시하고 자유롭게 새로운 세계를 창조하는 것이 가능할까? 현실을 무시하고 자유롭게 새로운 세계를 창조하는 것은 혼자서 하는 건 그나마 쉬울 것 같다. 협업을 한다면 현실을 무시하고 자유롭게 새로운 세계를 창조하는 것이 어려울 것 같다.
